# 配图 Prompt（中英双语）

## 规矩

1. 每张配图必须同时写好 **中文 prompt**（中文版作图用）和 **English prompt**（英文版作图用），两者描述同一画面，不得互相矛盾。
2. prompt 只描述画面本身，不写味道——味道描述由作者后续单独写，不进 prompt。
3. 图片本身不带文字（no text），中英版可共用同一张图；必须含文字的图片需分别生成。
4. 状态标记：✅ 已生成 / ✅ 草稿待生成。
