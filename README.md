# AI 摄影师：用文字拍照

### AI Photographer: Taking Photos with Words

给 13+ 零基础的 AI 图片摄影教程：先学传统摄影的 8 个核心概念，再把每个概念翻译成一句能指挥 AI 的话。

A zero-to-one AI photography tutorial for ages 13+. Learn the 8 core concepts of traditional photography first, then translate each into a prompt that directs AI.

## 快速开始

1. 先看 [大纲](outline.md)：12 章 + 附录，每章一句话。
2. 读 [引言：先尝一口](introduction.md)。
3. 从 [第 1 章](chapters/01-eight-decisions.md) 开始，每章结尾有一份填空题作业。

## 本书的三条规矩

1. **一章只讲透一个概念**：13 岁能听懂的话，例子全是青少年熟悉的东西（滑板、自拍、演唱会、奶茶、猫）。
2. **每张配图都有中英双语作图 prompt**：见 [chapters/image-prompts.md](chapters/image-prompts.md)。中文 prompt 作中文版图，English prompt 作英文版图，两者描述同一画面。
3. **每章一份填空题作业**：填上你感兴趣的东西，明天交一张图。作业是"拍/画"出来的，不是写出来的。
