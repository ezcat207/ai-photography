# 第 9 章：色彩——暖还是冷

同一家便利店，怎么拍出"深夜 emo"和"清晨希望"两种感觉？答案不在货架上，在温度里。

![深夜便利店，冷蓝色调](images/ch09-color.webp)

看这张图：深夜的便利店，冷蓝的灯光，少年独自站在关东煮前。明明关东煮是热的，整张照片却是"凉"的——色彩先定了情绪，内容才跟着走。

## 色彩是什么

**一句话**：画面的"温度"，先定情绪，再讲故事。

**13 岁版**：

- **暖色（黄、橙、红）**：热闹、怀旧、有食欲。火锅、夕阳、老街，暖一点才对味。
- **冷色（蓝、青）**：冷静、孤独、科技感。深夜、雨天、emo 时刻，冷一点才成立。
- **白平衡**：相机的"体温计"。它猜错了，白色会偏黄或偏蓝——有时候将错就错，反而是风格。
- **互补色**：橙和蓝是天生一对（日落配蓝天），放一起互相成就。电影海报最爱这招。

**两个冷知识**：
1. 想表达什么情绪，先定温度，再按快门——顺序别反。
2. 饱和度是"音量"：拉满就是喊，调低就是耳语。别一上来就拉满，容易变"杀马特"。

## 提示词翻译

- 暖："暖黄怀旧色调，夕阳氛围"
- 冷："冷蓝孤独感，深夜"
- 高饱和："高饱和，鲜艳"
- 低饱和："低饱和，莫兰迪灰调"
- 黑白："黑白，高对比"

## 可复现实验

同一家便利店/奶茶店，手机修图里色温往左拉到底（冷）、往右拉到底（暖），各存一张。问朋友：哪张像"深夜 emo"，哪张像"周末约会"——色彩课 5 分钟毕业。

## 翻车预警

- **打架翻车**：自动白平衡在混合光源下会"精神分裂"，一半黄一半蓝——手动锁定白平衡，或后期统一。
- **杀马特翻车**：饱和度 +100，草比荧光笔还绿——饱和度是味精，不是主菜。

## 作业：填空题（明天交一张图）

"拍____（一个地方，比如：我家楼下、学校操场），我想表达____（热闹 / 孤独 / 怀旧 / 清爽），所以色调____（暖 / 冷），因为____。"
