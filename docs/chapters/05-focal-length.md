# 第 5 章：焦段——站多远，看多"挤"

为什么别人拍的月亮像脸盆，你拍的只有米粒大？差的不是手机，是焦段。

![长焦压缩：操场晨跑的人群挤成一排](images/ch05-focal-length.webp)

看这张图：操场上晨跑的人，被"压"成了重叠的一排，远处的教学楼也被拽到了眼前。这是长焦的魔法——把空间压缩，像压扁的千层饼。

## 焦段是什么

**一句话**：镜头看世界的"宽窄"，决定远近的东西在画面里"挤"成什么样。

**13 岁版**：记住三档：

- **广角（数字小，如 16mm）**：视野大，近大远小夸张。自拍杆就是广角——腿显得长，宿舍全景一杆搞定。拍风景、拍建筑、拍大场面用它。
- **标准（50mm 左右）**：最接近人眼，最自然。拍日常、拍朋友聊天用它。
- **长焦（数字大，如 200mm）**：把远处"拽"到眼前，还压缩空间。拍月亮、拍球赛、偷拍猫都用它。人像黄金焦段是 85mm——脸不变形，背景还柔。

**三个冷知识**：
1. 你手机背后的三颗摄像头，就是三个焦段：超广角、广角、长焦。切镜头 = 换焦段。
2. 广角怼脸拍人，鼻子会变大——想害朋友就用超广角怼脸（开玩笑的，别）。
3. 长焦会放大抖动：200mm 端手一抖，画面晃成海——上三脚架或靠墙。

## 提示词翻译

- 要广角大场面："超广角，大场景，腿长，空间感"
- 要长焦压缩："长焦压缩，远处拉近，月亮巨大"
- 要自然人像："85mm 人像，脸不变形，背景柔和"

## 可复现实验

同一栋教学楼，手机三个镜头各拍一张：超广角 / 1x / 长焦。看楼"挤"成什么样——这是你离"压缩感"最近的一次。

## 翻车预警

- **怼脸翻车**：超广角贴脸自拍，鼻子变大三倍——自拍杆拉远点，或切到 1x。
- **手抖翻车**：长焦端手持，糊片率翻倍——先找支撑，再按快门。

## 作业：填空题（明天交一张图）

"拍____（远的东西，比如：月亮、操场对面的人），我想让它____（变大 / 被压缩 / 有空间感），所以用____（广角 / 长焦）。"

**示范**：拍"晚上的月亮"，我想让它"变大"，所以用"长焦"——切到手机最长的那颗镜头。
