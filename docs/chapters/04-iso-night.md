# 第 4 章：ISO 与夜景——天黑了怎么办

演唱会内场不让开闪光灯，你举起手机，拍出来全是雪花点。那不是手机坏了，是 ISO 被迫拉太高了。

![演唱会内场，舞台光束与人群剪影](images/ch04-iso-night.webp)

看这张图：舞台光束刺破黑暗，观众举起手机，人群是剪影。放大看暗部，有细细的颗粒——这就是高 ISO 的"噪点"。摄影师觉得：有颗粒的现场感，比一片漆黑强。

## ISO 是什么

**一句话**：相机的"夜视能力"，代价是噪点。

**13 岁版**：

- **ISO 100–400（白天）**：画面干净得像洗过。天亮就用它，别动。
- **ISO 800–3200（傍晚/室内）**：看得见了，暗部开始起颗粒。能接受。
- **ISO 6400+（深夜）**：雪花点开会。先保证"拍到"，再谈"拍好"。

**夜景三招**（按顺序用，别一上来就拉 ISO）：

1. **找光**：路灯、店招、舞台光——先挪到有光的地方，这是成本最低的一招。
2. **稳住**：把手机架在栏杆/桌上，用慢快门（第 3 章那招）代替高 ISO。
3. **补光**：实在没光，找朋友开手电筒从侧面打一下——人像瞬间干净三档。

记住顺序：**找光 > 稳住 > 拉 ISO**。直接拉 ISO 是懒人的做法，噪点是利息。

## 提示词翻译

- 要真实夜景感："夜景，轻微噪点颗粒，真实手机拍摄感"
- 要干净夜景："干净通透的夜景，低噪点"
- 要演唱会氛围："舞台光束，人群剪影"

## 可复现实验

今晚找个暗角落，同一场景拍两张：ISO 自动（手机会拉到很高）vs 专业模式手动 ISO 800 + 把手机架稳。对比噪点——你会亲眼看到"稳住"比"拉 ISO"值钱。

## 翻车预警

- **灾难组合**：ISO 拉满 + 数码变焦拉满 = 马赛克。变焦用两根腿走近，别用手指放大。
- **忘记调回来**：昨晚拍夜景 ISO 6400，今天白天忘了调回来，照片全过曝——养成习惯：天亮就调回 100。
